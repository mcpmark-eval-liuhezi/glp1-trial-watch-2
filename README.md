# GLP-1 RA in Type 2 Diabetes — Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on GLP-1 receptor agonists in type 2 diabetes.

This repo captures the late-stage landscape of currently recruiting Phase 3 studies of GLP-1 receptor agonists in adults with type 2 diabetes from ClinicalTrials.gov: one tracking issue per selected trial (sponsor, phase, planned enrollment, primary completion date) and a parent summary issue with the phase and sponsor-class breakdowns of the full recruiting search.
