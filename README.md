# GLP-1 RA Trial Watch

Tracking repository for the endocrinology group's quarterly pipeline review on **GLP-1 receptor agonists in type 2 diabetes**.

## Purpose

This repository captures the late-stage (Phase 3) recruiting landscape of GLP-1 receptor agonist trials in adults with type 2 diabetes captured from ClinicalTrials.gov. For each selected trial, a tracking issue records the NCT ID, sponsor, phase, planned enrollment, and primary completion date. A parent summary issue holds the aggregate breakdowns by phase and by sponsor class.

## Contents

- One tracking issue per selected late-stage trial (NCT ID, sponsor, phase, enrollment, primary completion date).
- A parent summary issue with the phase and sponsor-class breakdowns.

## Source

ClinicalTrials.gov registry searches for recruiting interventional studies of GLP-1 receptor agonists in type 2 diabetes.
